# Källor att ta in (prioriterad lista)

## P1 – obligatoriska primärkällor

| Prioritet | Källa | Varför kritisk | Behövs från |
|---|---|---|---|
| P1 | HSA Schema (objekt/attribut/kardinalitet) | Bas för formella attributkrav | Beställare/HSA-förvaltning |
| P1 | HSA tekniska specifikationer | Identifierare, formatregler, strukturella constraints | Beställare/HSA-förvaltning |
| P1 | HSA policy och regelverk | Ansvar, kvalitet, aktualitet | Beställare/HSA-förvaltning |
| P1 | HSA Admin-handbok/förvaltning | Praktiska skapande- och livscykelregler | Beställare/HSA-förvaltning |
| P1 | Tillämpningsanvisning vårdgivare/vårdenhet/enhet | Semantiska och strukturella vårdkrav | Beställare/HSA-förvaltning |
| P1 | Kodverksspecifikationer för HSA | Bindings, ValueSets, mappningsregler | Beställare/HSA-förvaltning |

## P2 – kritiska tillämpningskällor (beslutade)

| Prioritet | Källa | Varför kritisk | Behövs från |
|---|---|---|---|
| P2 | NPÖ relaterade krav på HSA-fält | Åtkomst, visning, spårbarhet | Tjänsteägare/integration |
| P2 | 1177 katalogbehov | Vårdsökning, kontaktvägar, publicering | Tjänsteägare/integration |
| P2 | Katalogsynk till EHR-system | Vilken organisationsdata som behövs i mottagande system | EHR-förvaltning/integration |
| P2 | Behörighets/uppdragsflöden | Implicit hierarki och ansvar | IAM/behörighetsansvariga |

## Inlämningsformat

För varje källa vill vi få:

1. Dokumentnamn + version + datum
2. Ägare/förvaltare
3. URL eller fil
4. Giltighetsstatus (gällande/utgående)
