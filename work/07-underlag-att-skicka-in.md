# Underlag att skicka in (för att driva arbetet vidare)

Nedan är den exakta lista vi behöver från dig/förvaltning för att kunna gå från utkast till normativ kravkatalog.

## A. Formella HSA-källor (obligatoriska)

1. HSA Schema (senaste gällande version)
2. HSA tekniska specifikationer (identifierare/format/struktur)
3. HSA policy och regelverk
4. HSA Admin-handbok/förvaltningsinstruktion
5. Tillämpningsanvisningar för vårdgivare/vårdenhet/enhet
6. Kodverksspecifikationer (verksamhetskod, organisationstyper, kontaktvägar)

## B. Tillämpningskällor (prioriterade)

7. NPÖ: vilka HSA-fält används för visning/spårbarhet/åtkomst
8. 1177: vilka HSA-fält används för vårdsökning/kontakt/publicering
9. EHR-katalogsynk: vilket minsta organisationsunderlag som krävs i mottagande system

## Format per källa

För varje källa, skicka:

- Dokumentnamn
- Version + datum
- Ägare/förvaltare
- Länk eller fil
- Status (gällande/utgående)

## Snabbspår

Om du vill, kan du börja med endast dessa tre först:

- HSA Schema
- HSA policy/regelverk
- NPÖ underlag

Det räcker för att vi ska kunna uppgradera flera av utkastkraven till verifierade krav i nästa iteration.
