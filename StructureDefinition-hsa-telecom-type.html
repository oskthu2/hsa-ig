Extension: HSA Kontaktvägstyp

Official URL: https://hsa.inera.se/fhir/StructureDefinition/hsa-telecom-type Version: 0.1.0
Draft as of 2026-11-04 Computable Name: HsaTelecomTypeExtension

Klassificerar kontaktvägstyp för att skilja direkttelefon från växeltelefon, publik telefon, innehållsansvarig e-post m.fl. Mappar till LDAP-kontexten (telephoneNumber, hsaSwitchboardNumber etc.).

Context of Use

    Denna extension kan användas på följande element

    • Element-ID: ContactPoint

Usage info

Användningar:

  • Använd denna Extension: HSA Catalog Organization
  • Exempel för denna Extension: Blekingesjukhuset, Hjärtmottagningen Karlskrona, Blekinge Primärvård AB, Region Blekinge and Ronneby Vårdcentral

Du kan också kontrollera användningar i FHIR IG-statistiken
